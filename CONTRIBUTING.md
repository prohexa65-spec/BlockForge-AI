# Contributing to BlockForge AI

Thanks for helping improve the toolkit.

## Before opening a change

- State the Minecraft Bedrock version your change targets.
- Prefer official, documented Bedrock formats and APIs.
- Keep generated files small, readable, and easy to inspect.
- Add or update validation when adding a new file type.
- Do not commit API keys, access tokens, personal data, or large generated binaries.
- Test the browser interface on a narrow mobile viewport.

## Pull requests

Describe the problem, the change, the target version, and how you tested it. Include a small example project when useful.
