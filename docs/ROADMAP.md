# Roadmap

## Milestone 0 — Foundation
- Repository structure and project conventions
- Mobile-first manifest builder
- UUID and JSON validation helpers

## Milestone 1 — Data-driven pack templates
- Custom item templates
- Custom block templates
- Friendly entity and creature templates
- Recipes, loot tables, and spawn rules
- Resource-pack texture and sound metadata helpers

## Milestone 2 — Developer workflow
- Project tree editor
- Version compatibility profiles
- Full project validation
- Export as a Bedrock add-on archive

## Milestone 3 — AI-assisted authoring
- Prompt-to-feature-plan parser
- Template selection and file generation
- Explainable validation and repair suggestions
- Optional server-side model provider integration

## Design principles
- Mobile-first and low-resource
- Offline-capable where practical
- Version-aware rather than assuming one universal format
- Generated output stays editable by humans
- No secrets in browser code or repository history
